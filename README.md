# CLI-Games
Collection of games that can be played in the terminal!

## Features
- 3 games: Tic-Tac-Toe, Snakes and Ladders, and Hangman
- Easy to understand and start playing, but also fun to play by yourself or with a friend
- Colorful details!

## How to Run

Simply go to the initial release, download the .exe file, and start playing! Note: this game only works on Windows. Support for Linux and Mac may arrive with a later release.
